# Empty Project Template

This is an empty project template that serves as a starting point for your custom application.

## Structure

This template provides a clean slate with minimal configuration. You can build any type of application on top of this foundation.

## Getting Started

1. Navigate to the `.aimfire` directory
2. Run `compile.bat` to set up environment variables
3. Start building your application!

## Environment Configuration

Environment variables can be configured in `.aimfire/additional_settings.json`. The setup script will generate a `.env` file in the project root.

## Next Steps

- Add your application code
- Install required dependencies
- Update this README with your project documentation

## Template Information

- **Type**: Empty/Starter Template
- **Purpose**: Custom application development
- **Configuration**: Environment variables via `.env` file
